# AGENTS.md

## Cursor Cloud specific instructions

Páramo Quest is a **local-first, offline PWA** (React 19 + Vite + TypeScript, Tailwind CSS v4, Dexie/IndexedDB, `vite-plugin-pwa`). There is **no backend, login, network API, or database service** — all user data lives in the browser's IndexedDB. So there are no services to boot beyond the Vite dev server.

Standard commands live in `package.json` scripts:
- `npm run dev` — Vite dev server on `http://localhost:5173/` (development mode; use this, not the production build, while developing).
- `npm run test` — domain unit tests (`vitest run`).
- `npm run lint` — `oxlint`.
- `npm run build` — production build (`tsc -b && vite build`) + PWA assets.

Non-obvious gotchas:
- **The app simulates "today".** The plan starts **2026-07-13**; the real current date usually has no scheduled tasks, so a fresh load can look empty. To see tasks, open with the URL param `?fecha=2026-07-13` (any `?fecha=YYYY-MM-DD`), or go to **Ajustes → "Día 1 del plan"**.
- **State persists in IndexedDB per browser profile.** Completed tasks/XP survive reloads. To start clean, use **Ajustes → "Reiniciar todo el progreso"** (it asks for a native `confirm()`).
- **`src/data/plan.json` is the committed source of truth for the curriculum.** It is nominally generated by `scripts/parse_plan.py` from `../plan-carrera-geoespacial.md`, but that source markdown is **not in this repo**, so `npm run parse-plan` cannot run here. Edit `src/data/plan.json` directly, and keep `src/data/flashcards.ts` (each card's `weekId`) in sync so review cards unlock with the week that teaches their topic.
- **`src/domain/__tests__/planCursor.test.ts` reads the real `plan.json`** and hard-codes that day 1 (`2026-07-13`) has exactly 2 tasks, the next task day is `2026-07-14`, and there's a Fri `2026-07-17` → Mon `2026-07-21` gap (weekend + the July 20 holiday). Preserve these invariants when editing the early weeks. Other domain tests use mock plans and are decoupled from `plan.json` content.
